# Sacred Audio Recording Pack

This directory contains twelve traditional Catholic recordings selected for a
future sacred-audio picker. The pack deliberately favors Gregorian chant and
long-established seasonal hymns over contemporary devotional music.

The licensing check covers the **recording and performance**, not only the
underlying public-domain composition. Source pages are retained below so a
future distributor can reproduce the attribution exactly. Files marked
CC BY-SA must keep their attribution, license link, and share-alike terms if
they are remixed or otherwise adapted.

All files were downloaded from Wikimedia Commons. Three files are Commons'
own Ogg Vorbis transcodes of another format; they were downloaded unchanged
and are identified below. The remaining files are the original Commons audio.

## Validation

Each file was probed successfully as Ogg Vorbis audio. Validation used
`ffprobe-static` 3.1.0's bundled arm64 `ffprobe` binary (FFprobe 4.4) and checked
the first audio stream plus container duration and size. No malformed or
non-audio files were accepted.
