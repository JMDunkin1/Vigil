Bundled Baroque Focus Recordings
================================

These files are bundled for the Focus Studio sound picker. They were downloaded
from Wikimedia Commons and selected because the Commons file pages mark the
recordings as CC0 / public domain dedication or public-domain-marked works.

- `bach-goldberg-aria-harpsichord.ogg`
  - J. S. Bach, Goldberg Variations, Aria, harpsichord.
  - Source: https://commons.wikimedia.org/wiki/File:Bach.Aria.Goldberg-Variationen.WerckmeisterIII.Harpsichord.ogg
  - License on source page: CC0 1.0 Universal Public Domain Dedication for the performance; composition public domain.
- `bach-invention-8-harpsichord.ogg`
  - J. S. Bach, Invention 8, BWV 779, harpsichord.
  - Source: https://commons.wikimedia.org/wiki/File:J.S._Bach%27s_Invention_8_(BWV_779)_on_harpsichord.ogg
  - License on source page: CC0 1.0 Universal Public Domain Dedication for the performance; composition public domain.
- `bach-italian-concerto-presto.ogg`
  - J. S. Bach, Italian Concerto, BWV 971, third movement.
  - Source: https://commons.wikimedia.org/wiki/File:J._S._Bach_-_Italian_Concerto,_BWV._971_-_3._Presto.ogg
  - License on source page: CC0 1.0 Universal Public Domain Dedication.
- `handel-harmonious-blacksmith.ogg`
  - George Frideric Handel, Suite No. 5 in E major, "The Harmonious Blacksmith".
  - Source: https://commons.wikimedia.org/wiki/File:Handel_-_Suites_for_Harpsichord_-_No.5_in_E_major_-_The_Harmonious_Blacksmith.ogg
  - License on source page: CC0 1.0 Universal Public Domain Dedication.
- `scarlatti-sonata-k87.ogg`
  - Domenico Scarlatti, Sonata in B minor, K.87, digital harpsichord.
  - Source: https://commons.wikimedia.org/wiki/File:Domenico.Scarlatti.Sonata.b.minor.Kirkpatrick.87.ogg
  - License on source page: CC0 1.0 Universal Public Domain Dedication.
- `scarlatti-sonata-k466.ogg`
  - Domenico Scarlatti, Sonata in F minor, K.466, digital harpsichord.
  - Source: https://commons.wikimedia.org/wiki/File:Domenico.Scarlatti.Sonata.f.minor.Kirkpatrick.466.ogg
  - License on source page: CC0 1.0 Universal Public Domain Dedication.
