Bundled Nature Focus Recordings
================================

These files are bundled for the Focus Studio sound picker. They were downloaded
from Wikimedia Commons and selected because the Commons file pages mark the
recordings as public domain or public-domain-released works.

- `rain.ogg`
  - Rain field recording from PDSounds.
  - Source: https://commons.wikimedia.org/wiki/File:Rain_(1).ogg
  - License on source page: public domain release.
- `ocean-waves.ogg`
  - Shore wave field recording.
  - Source: https://commons.wikimedia.org/wiki/File:Waves.ogg
  - License on source page: public domain release.
- `storm-thunderbolts.ogg`
  - Thunderstorm field recording from PDSounds.
  - Source: https://commons.wikimedia.org/wiki/File:Storm_thunderbolts.ogg
  - License on source page: public domain release.
- `forest-lawn-creek.ogg`
  - Creek field recording.
  - Source: https://commons.wikimedia.org/wiki/File:Forest_lawn_creek.ogg
  - License on source page: public domain release.
