# Vigil Companion browser-store listing

## Single purpose

Vigil Companion connects supported Chromium tabs to the Vigil app running on the same Mac. It applies the user's local site and path rules, enforces supported SafeSearch settings, records local browser activity for the Vigil dashboard, and removes distracting page features the user has chosen to hide.

## Suggested listing copy

**Name:** Vigil Companion

**Summary:** Apply your local Vigil focus rules inside Chrome and other Chromium browsers.

**Description:**

Vigil Companion adds page-level protection to the Vigil Mac app. It checks the rules you configured in Vigil, blocks matching pages, keeps supported search filters enabled, and hides selected distracting feeds or page features. The companion communicates with Vigil over the loopback connection on your own Mac. It does not sell data, run advertising, or send browsing history to Vigil's developer.

The Vigil Mac app is required. After installation, open Vigil's Guided Setup and wait for the Browser Companion step to show Verified.

## Permission justifications

- `tabs` and `webNavigation`: observe the active tab URL and navigation changes so local site, path, schedule, and usage rules can be evaluated.
- `declarativeNetRequest`: install the local blocking and SafeSearch redirects generated by Vigil.
- `storage`: retain the loopback endpoint, pairing token, cached cleanup preferences, and last synchronized local rule snapshot and status.
- `alarms`: keep local policy refreshes and time-limited rule expiration reliable without continuous execution.
- Access to HTTP and HTTPS pages: evaluate user-configured URL rules and run the content scripts that hide selected distracting page features.
- Access to `127.0.0.1` and `localhost`: pair with and receive policy from the Vigil app on the same computer.

## Privacy disclosure

The extension processes URLs, page structure, and limited browser activity to provide its single purpose. These data remain on the user's Mac and are not sold, used for advertising, or transmitted to the developer. The browser-store privacy answers and the public Vigil privacy policy must stay consistent with this behavior before upload.

## Publisher checklist

- Run `npm run package:extension` and upload that draft zip to a newly created Chrome Developer Dashboard item without publishing it.
- Copy the dashboard item's public key into `manifest.json`, confirm its derived item ID matches both `build/browser-store.json` and `BUILT_IN_CHROME_EXTENSION_ID`, then rebuild and upload the aligned zip.
- Publish a public privacy-policy URL that matches the repository policy.
- Supply original Vigil screenshots and the included 128 px icon.
- Complete domain/email verification for the publisher account.
- Re-review every requested permission and remove any permission no longer required.
- After review makes that exact item publicly installable, set `published` to `true` in `build/browser-store.json` and run `npm run package:extension:release`. Production Guided Setup then opens only the allowlisted Chrome Web Store item; unpacked installation remains a development fallback.
