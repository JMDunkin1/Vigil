# Vigil Sound page — minimal layout concepts

These concepts show the Sound page in its default, collapsed state. They deliberately
defer track rows and recording attribution until a category is opened.

1. **Quiet Stack** — compact horizontal player above five flat disclosure rows.
2. **Centered Player** — waveform-led central stage above one compact category strip.
3. **Quiet Split** — spacious player field beside a plain category index.
4. **Player Dock** — library-first page with a shallow persistent player at the bottom.
5. **Open Canvas** — slim top navigation creates a full-width player and library.

Every prompt preserved the current track, live waveform, single Listen/Pause action,
five category summaries, selected Baroque state, app navigation, and account access.
The prompts explicitly prohibited expanded track lists, visible attribution in the
collapsed state, extra media controls, search, cards, badges, album art, and decoration.

Generated with the built-in image tool using the supplied screenshot as a visual and
functional reference, not as an edit target.
