# Vigil Sound page — alternate layout concepts

These are layout explorations, not implementation-ready screenshots. They use the current
Sound page as a visual reference while preserving its actual display contract.

## What the page needs to display

- Current track title
- A live, signal-driven waveform
- One primary Listen/Pause action
- Five sound-library disclosures:
  - Church — 12 sounds
  - Minecraft — 8 tracks
  - Baroque — 6 sounds
  - Nature — 4 sounds
  - Noise & tones — 5 sounds
- The selected track within its library group
- Track title, secondary metadata, and Play/Ready state
- Recording attribution with source and license links inside the relevant expanded group
- Existing Vigil app navigation, selected Audio state, account identity, and Settings entry

The current page intentionally does not display volume, timers, search, queue, favorites,
skip controls, or redundant status/description copy.

## Concepts

1. **Listening Gallery** — panoramic waveform hero with a compact category index and a
   featured expanded library card.
2. **Library Browser** — category tabs, a scannable track table, and a persistent
   right-side player.
3. **Audio Console** — library-first workspace with a fixed waveform player dock along
   the bottom.
4. **Listening Room** — immersive waveform stage beside a full-height accordion library.
5. **Editorial Ledger** — top navigation replaces the sidebar, creating a wider waveform
   canvas and a full-width track ledger.

## Prompt set

All five images were generated as realistic, shippable desktop UI mockups using the
supplied screenshot as a visual-identity and feature reference—not as an edit target.
Each prompt required the same exact content, dark charcoal/ivory/bronze palette, serif-led
typography, live waveform, single Listen action, five library groups, expanded Baroque
track list, selected Italian Concerto state, and source/license attribution. Each prompt
then specified one of the five distinct layout structures above and prohibited invented
media controls or placeholder text.
